I'm a Computer Science undergraduate (B.Tech CSE, Integral University, 2023–2027) building toward one goal: **software that ships and holds up in production.** My work sits across three lanes — full-stack product engineering on the MERN stack, backend systems in Java with Spring Boot, and applied AI/GenAI — pulled together with a growing base in cloud and IoT.
